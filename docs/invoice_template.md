# نموذج الفاتورة والتقارير الشهرية

## 1. نموذج الفاتورة (للطباعة العادية)
- **رأس الفاتورة**: اسم الكانتين، تاريخ ووقت الفاتورة، رقم الفاتورة، اسم الموظف.
- **تفاصيل المريض (إن وجد)**: اسم المريض ورقم الملف.
- **الجدول**:
  - الصنف
  - الكمية
  - سعر الوحدة
  - الإجمالي الفرعي
- **ذيل الفاتورة**: 
  - الإجمالي الكلي
  - طريقة الدفع (نقدي / حساب مريض / مختلط)
  - المبلغ المدفوع والمتبقي.

## 2. التقارير الشهرية (تقفيلة الشهر - نموذج Word)
هذا التقرير سيتم تصديره كملف Word بناءً على Template ثابت:
- **القسم الأول: الكانتين**
  - إجمالي المبيعات
  - إجمالي المشتريات / تكلفة البضاعة المباعة
  - إجمالي المصروفات
  - صافي الربح
- **القسم الثاني: البوفيه**
  - إجمالي المبيعات
  - إجمالي المصروفات (مواد خام)
  - صافي الربح
- جدول تفصيلي للأصناف التي تم بيعها (الكمية، تكلفة الشراء، سعر البيع، هامش الربح).
