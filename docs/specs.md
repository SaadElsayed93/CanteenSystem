# مواصفات نظام الكانتين (CanteenSystem)

## 1. المقدمة
نظام لإدارة مبيعات ومخزون وحسابات الكانتين والبوفيه. يعمل النظام على شبكة محلية ويدعم 4 أجهزة تعمل بالتزامن. 

## 2. النطاق
- **المبيعات**: نقطة بيع (POS) سريعة تدعم الدفع النقدي وعلى حساب المرضى.
- **المخزون**: إدارة الأصناف والمشتريات وحركات الدخول والخروج.
- **المرضى**: حسابات المرضى والإيداع والسحب وتتبع المديونيات.
- **الخزينة**: تتبع النقدية في مختلف طرق الدفع وتسجيل المصروفات.
- **التقارير**: تقارير يومية للعساكر وتقارير شهرية للإدارة مع نماذج ثابتة (Word).

## 3. المتطلبات غير الوظيفية
- **نظام التشغيل**: Windows 7 أو 10 للسيرفر.
- **الرامات**: 4 جيجا بايت كحد أدنى.
- **الشبكة**: LAN (بدون احتياج للإنترنت).
- **التقنية**: Node.js + Express + Prisma + React + PostgreSQL.
