# مسارات العمل (Workflows)

## 1. فاتورة الشراء
1. يقوم المستخدم بإنشاء فاتورة شراء جديدة واختيار المورد (النشط).
2. إضافة الأصناف وتحديد الكميات وأسعار الشراء.
3. عند الحفظ، يتم حفظ الفاتورة وإنشاء الدفعات (Batches).
4. تزيد كمية المخزون لكل صنف بناءً على الدفعة.
5. يُسجل المبلغ المستحق في رصيد المورد (ينقص عند الدفع).

## 2. عملية البيع (POS)
1. يختار المستخدم الأصناف بالبحث أو الباركود.
2. يراجع الإجمالي ويختار طريقة الدفع (نقدي، حساب، مختلط).
3. عند التأكيد:
   - تحفظ الفاتورة بسعر البيع اللحظي (Snapshot).
   - يُخصم المخزون بنظام (FIFO).
   - في حال كان المخزون سالب، يستمر البيع مع تحذير.
   - إذا كان الدفع على الحساب، يُخصم المبلغ من حساب المريض.
   - يُضاف المبلغ النقدي لرصيد الخزينة (طريقة الدفع المختارة).
   - يتم عمل Commit للـ Transaction (إما كل شيء ينجح أو يُلغى كل شيء).

## 3. المرتجعات
- **مرتجع مبيعات**: يزيد المخزون ويعيد المبلغ لرصيد المريض أو الخزينة. يسجل كحركة مستقلة تشير للفاتورة الأصلية.
- **مرتجع مشتريات**: ينقص المخزون وينقص المبلغ المستحق للمورد.
