# 🏪 نظام إدارة الكانتين المتكامل (Canteen Management System)

> **نظام شامل لإدارة الكانتين والبوفيه، نقاط البيع، المخزون، الموردين، حسابات وأمانات المرضى، والخزائن والورديات اليومية.**  
> مصمم ليعمل بكفاءة فائقة على أجهزة **Windows 7 SP1** وما فوق، برامات 4GB أو أقل، وبدون الحاجة لإنترنت نهائياً.

---

## 🌟 الميزات الرئيسية للنظام

### 1. نقطة البيع السريعة (POS Pro)
- شبكة أصناف تفاعلية تدعم مسح الباركود، البحث الذكي، والصور.
- اختصارات لوحة المفاتيح الكاملة لسرعة الخدمة في الطوابير (`F9` إنهاء كاش، `F2` بحث، `F4` دفع على الحساب).
- إدخال كميات يدوي فوري، وزر تفريغ سلة، ومؤثرات صوتية تفاعلية.
- دعم طباعة البون الحراري (Thermal 80mm) وفواتير A4/A5، مع إمكانية تفعيل أو تعطيل البون الحراري تلقائياً.
- **قفل البيع التلقائي عند إغلاق اليومية:** لا يمكن البيع إلا عند وجود يومية مفتوحة رسمياً.

### 2. إدارة الورديات ونظام اليومية المستمر (Daily Shift Engine)
- دورة حياة متكاملة لليومية (`DailyShift`): فتح اليومية برصيد بداية اليوم، وتقفيل الوردية بعد النقدية الفعلي.
- دعم الورديات العابرة لمنتصف الليل (مثلاً من 9 صباحاً حتى 1 صباح اليوم التالي) دون أي تأثر بتقلبات التاريخ الميلادي.
- احتساب العجز والزيادة تلقائياً مع ترحيل النقدية المحصلة من الدرج للخزينة الرئيسية وإصدار إيصال تقفيل معتمد.
- فتح وإغلاق اليومية بضغطة زر واحدة من الشاشة الرئيسية (`Home Screen`) ومن شاشة الخزينة.

### 3. الإدارة المالية والقنوات الثلاث المعتمدة
- إلغاء وسيلة "تحويل" نهائياً، وتثبيت 3 قنوات مالية رسمية:
  1. `نقدي (الدرج)`: النقدية التشغيلية اليومية للكاشير.
  2. `فودافون كاش`: محفظة المعاملات الإلكترونية.
  3. `الخزينة (الرئيسية)`: الخزينة المركزية الآمنة لتوريد عهد الوردية والمدفوعات الكبرى.
- تحويل تبادلي مباشر بين أي قناتين (من درج لكاش، من كاش لخزينة، إلخ) دون اعتباره إيراداً أو مصروفاً.
- سجل منصرفات موحد وشامل يسجل كافة المدفوعات (مصروفات تشغيلية، سداد فواتير مشتريات للموردين، وردود أمانات المرضى المغادرين، ومسحوباتهم).

### 4. كشف حساب الموردين وفواتير الشراء الذكية
- كارت إجمالي مديونيات الموردين في النظام.
- كشف حساب تفصيلي لكل مورد مع سجل تاريخي بكافة الفواتير والدفعات والمتبقي، وطباعة كشف الحساب.
- سداد دفعات للمورد مباشرة من المصروفات مع خصم فوري للمديونية وتوزيعها على الفواتير المفتوحة.
- **دعم الباركود في فاتورة الشراء:** مسح الباركود لإضافة الأصناف، وإمكانية إنشاء صنف جديد أو تعديل بيانات أي صنف فورياً من داخل الفاتورة دون مغادرة الشاشة.

### 5. ملفات المرضى والأمانات والمديونيات
- فصل واضح ودقيق بين:
  - `ديون المرضى للكانتين (مستحقة لنا)` للأرصدة السالبة.
  - `أموال وأمانات المرضى المستحقة لهم (أمانات مودعة)` للأرصدة الموجبة والواجب ردها عند الخروج.
- كشف حساب تفاعلي لكل مريض مع إيداع، سحب، وشراء على الحساب.
- تصفية المريض ونقله للأرشيف بنقرة زر مع رد المتبقي أو تحصيل المديونية تلقائياً عبر الخزينة.

### 6. التقارير ولوحة التحكم المزدوجة
- لوحة تحكم ذكية للكاشير (إحصائيات وردية لحظية) ولوحة تحكم للمدير (أرباح شهرية، قيمة المخزون، مؤشرات مالية).
- تقارير تفصيلية: مبيعات، مشتريات، مصروفات، أرصدة المرضى، ديون الموردين، تقييم المخزون، ونواقص البضاعة.
- طباعة A4 مباشرة وتصدير متقدم لجداول Excel عبر `ExcelJS`.

## 🛠️ البنية التقنية والتوافق مع Windows 7

| الطبقة | التقنية المعتمدة | سبب الاختيار |
|---|---|---|
| **الواجهة (Frontend)** | React 18 + Vite 5 + Tailwind CSS RTL | واجهة سريعة، تصميم عربي متناسق، مستهدفة لـ ES2015 لتعمل على متصفحات Win 7 |
| **الخادم (Backend)** | Node.js (Express.js) | خفيف وسريع، متوافق مع Node 16 / Node 14 |
| **قاعدة البيانات** | SQLite (عبر Prisma ORM) | ملف محلي واحد خفيف (< 20MB RAM)، بدون سيرفرات خارجية ثقيلة |
| **الأمان والتشفير** | JWT + `bcryptjs` | جافاسكريبت نقية بنسبة 100% بدون أي ملفات C++ مجمعة أو DLLs تطلب ويندوز حديث |
| **التصدير المتقدم** | ExcelJS | توليد ملفات Excel `.xlsx` منسقة وموجهة لليمين (RTL) |
| **الشبكة المحلية** | Offline Local LAN | يعمل بدون أي حاجة للإنترنت نهائياً على 4 أجهزة داخلية |

## 🚀 تعليمات التشغيل السريع (للمطورين)

```bash
# 1. تشغيل الباك إند
cd backend
npm install
npx prisma db push
node prisma/seed.js
npm run dev

# 2. تشغيل الواجهة (Frontend)
cd frontend
npm install
npm run dev
```
