# CanteenSystem (نظام إدارة الكانتين)

نظام متكامل لإدارة الكانتين والبوفيه.
مبني باستخدام Node.js (Express) و React و PostgreSQL و Prisma.

## الميزات الأساسية:
- نقطة بيع (POS) سريعة
- إدارة المخزون والمشتريات
- حسابات المرضى
- الخزينة والمصروفات
- تقارير مفصلة (يومية وشهرية)
